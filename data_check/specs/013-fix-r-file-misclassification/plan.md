# Implementation Plan: Fix R File Misclassification and CSV Read Errors

**Branch**: `013-fix-r-file-misclassification` | **Date**: 2026-03-18 | **Spec**: [spec.md](spec.md)

## Summary

Fix two bugs in `run_index()` that cause `.R`/image files to be processed as data files and empty CSVs to emit internal R errors. The aggregate-folder type-inheritance mechanism is fixed by adding an extension-override lookup applied after sentinel expansion. The empty-CSV crash in `sniff_delimiter()` is fixed by guarding against `character(0)` returned by `readLines`. A harmless "incomplete final line" warning from `read.delim` is suppressed.

## Phase 0: Research

All findings documented in [research.md](research.md).

**Key conclusions**:
1. `.R`/image misclassification: aggregate sentinel type propagates to all files without extension correction. Fix: `AGGREGATE_EXT_OVERRIDE` lookup applied only to expanded aggregate files.
2. Empty CSV crash: `sniff_delimiter()` assigns `character(0)` to `line` when file is empty; `if (nchar(...))` throws "argument is of length zero". Fix: `length()` guard before `nchar` check.
3. Incomplete-final-line warning: cosmetic; suppress with `suppressWarnings()` scoped to `read.delim()` call.
4. All five constitution principles satisfied — no violations, no Complexity Tracking needed.

## Phase 1: Design

Full design in [data-model.md](data-model.md) and [quickstart.md](quickstart.md).

**`AGGREGATE_EXT_OVERRIDE`** — named character vector constant in `0_index.R`:
- 19 code extensions → `"code"`
- 14 asset extensions → `"asset"`
- 7 data extensions → `"data"`
- Ambiguous extensions (`.txt`, `.dat`, `.rda`, `.rdata`, unknown) — NOT in map; retain sentinel type

**Application point**: immediately after building `agg_expanded_df` in Step 7 of `run_index()`. Three lines of code using vectorised `tools::file_ext()` + named-vector lookup.

**`sniff_delimiter()` fix**: two new guard lines — one inside the loop (`if (length(line) == 0) break`), one after (`if (length(line) == 0) return(",")`).

**`read_data_head()` warning suppression**: wrap existing `read.delim()` call in `suppressWarnings()`.

**No contracts directory needed** — this is a purely internal pipeline fix with no external interface changes.
